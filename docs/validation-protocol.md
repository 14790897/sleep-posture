# 数据采集与验证方案

目标不是“做出一个能分类的 demo”，而是得到**可复现、可解释、不会自欺**的四类睡姿识别结果。所有结论必须能追溯到原始 CSV、标签和脚本。

## 1. 类别定义

| 类别 | 定义 | 主要重力方向（传感器坐标） |
|---|---|---|
| 仰卧 supine | 背部朝下，胸部朝上 | `az ≈ +1 g` |
| 俯卧 prone | 胸部朝下 | `az ≈ -1 g` |
| 左侧卧 left | 身体左侧朝下 | `ax ≈ -1 g` |
| 右侧卧 right | 身体右侧朝下 | `ax ≈ +1 g` |
| 过渡 moving | 翻身、坐起、调整 | 不参与四类准确率 |

> 坐标前提：元件面朝外、`TOP` 朝头。反装会让左右互换。

判定以**躯干朝向**为准，不以头部朝向为准。手臂、腿的位置不改变标签。

## 2. 设备与材料

- v0 原型：ESP32-C3 + BMI270（或 LSM6DS3TR-C）+ 500 mAh 电池 + 35–40 mm 弹性胸带。
- 手机：录像，画面里必须同时看到**时钟**（另一台手机/电脑屏幕）和受试者躯干。
- 卷尺/记号笔：记录带子位置、传感器位置。
- 记录表：`data/sessions.csv`（见第 8 节）。
- 可选：压力垫/压力传感阵列作为独立参考；没有也不影响主流程。

## 3. 实验阶段

### A. 台架静态测试（不上身，30 分钟）

目的：确认坐标系、量程、噪声、零偏。

1. 设备平放桌面，`+Z` 朝上，静止 60 s，记录。
2. 依次让 `+Z` 朝下、`+X` 朝上、`+X` 朝下、`+Y` 朝上、`+Y` 朝下，各 30 s。
3. 用 `tools/ble/posture_ref.py eval` 检查：六个方向的重力分量应符合 ±1 g，交叉轴 < 0.1 g。
4. 静止 2 分钟，发送 `0x03` 陀螺校准；确认零偏写入后，静止时角速度模长 < 2 °/s。

通过标准：六面重力方向正确、无轴映射错误、静止噪声可控。

### B. 佩戴静态四点（1–2 小时）

目的：验证穿戴状态下四类可分，建立第一版混淆矩阵。

1. 按标准位置戴好：胸骨正中，`TOP` 朝头部，带子不勒。
2. 每个姿态 3 分钟 × 3 轮，顺序随机化（可用 `shuffle` 决定），避免总是同一顺序。
3. 每段开始前，受试者摆好姿势、盖好被子，静置 30 s 再开始记录；记录员在 logger 里设置对应标签。
4. 段间休息 1 分钟，允许调整；调整期间不记录标签。
5. 同步录像；视频里出现时钟，便于事后核对。

通过标准（稳态，跳过每段前 10 s）：

- 四类稳态时间加权准确率 ≥ 95%；
- 每类 recall ≥ 90%；
- `unknown` 比例 < 5%。

不通过时，先查佩戴方向/带子位置，再查阈值，不要急着上机器学习。

### C. 整夜自然睡眠（至少 3 晚）

目的：真实睡姿分布、翻身、被子/枕头干扰、长时间稳定性。

1. 睡前戴好，启动 logger，录视频（可选但推荐）；记录当晚床垫、枕头、被子、睡衣。整夜采集建议 `--rate 5` 或 10（仍 50 Hz 采样，降低 BLE Notify 频率），否则 500 mAh 电池可能只够 5–10 h。
2. 不要求整夜保持某个姿势；自然睡。
3. 记录员（可以是本人）在睡前/醒后记录大致的入睡、醒来、夜间醒来时间。
4. 视频用于事后逐段标注；若不方便录整夜，至少录前 2 小时和后 2 小时。
5. 每晚一个 CSV，文件名含夜晚编号，例如 `data/raw/night01_20261103.csv`。

建议的 3 晚设计：

| 夜晚 | 变量 | 目的 |
|---|---|---|
| N1 | 基线：常用睡衣/被子/枕头 | 主结果 |
| N2 | 换一套睡衣或被子厚度 | 检查衣物/被子影响 |
| N3 | 换枕头高度或床垫软硬（如可） | 检查支撑面影响 |

通过标准（初版目标，可随数据调整）：

- 稳态时间加权准确率 ≥ 85%；
- macro-F1 ≥ 0.80；
- 仰卧 recall ≥ 90%，俯卧 recall ≥ 65%（拉伸目标 80%），左/右 recall ≥ 80%；
- `unknown` < 10%；
- 每小时误切换 < 5 次；
- 无整夜数据中断（丢包率 < 1%，或设备侧离线日志补齐）。

> 俯卧是最难且最少见的类，文献单研究胸骨俯卧敏感度约 39%（样本少、CI 宽）。不要把“总体 95%”当成目标；先看俯卧单独召回，再谈总体。

### D. 干扰因素专项（可选，按需）

- 被子盖到胸口 vs 盖到腰部；
- 枕头高/低；
- 睡衣厚/薄；
- 带子位置上下移动 2 cm；
- 上腹部 vs 胸骨位置对比。

每次只改一个变量，记录在 `sessions.csv`。

## 4. 地面真值（ground truth）

优先级从高到低：

1. **视频 + 时钟**：事后按时间轴标注四类；过渡段标 `moving`。
2. **记录员实时打标**：用 `ble_logger.py --schedule` 或手机端按钮，记录标签与时间。
3. **压力垫**：作为独立参考，不替代视频；压力垫的类别定义需要与本文一致。
4. **自报**：只用于整夜粗粒度（入睡/醒来），不用于逐段准确率。

标注规则：

- 姿态稳定 10 s 后才算进入该姿态；翻身过程标 `moving`。
- 被子遮住身体时，以可见的肩/髋朝向判断。
- 不确定的片段标 `unknown`，不要猜；`unknown` 不进入四类混淆矩阵，但单独统计比例。
- 两人独立标注一段 10 分钟视频，计算一致率；不一致处讨论后定规则。

## 5. 数据划分与防泄漏

- **按夜晚分组**：同一晚的数据只能出现在训练或测试的一侧。用 `LeaveOneGroupOut`（`posture_ref.py train` 已实现）。
- 同一姿态块的相邻窗口高度相关，不能随机打散；窗口按块分组。
- 标准化/特征选择只在训练折内拟合，不要用全量数据算均值方差。
- 先跑阈值基线，再跑随机森林；如果 ML 没有稳定超过基线，保留基线。

## 6. 评价指标

| 指标 | 定义 | 用途 |
|---|---|---|
| 稳态时间加权准确率 | 每段跳过前 10 s，按采样间隔加权 | 主指标 |
| 30 s epoch 准确率 | 每 30 s 多数投票后与真值比 | 与睡眠文献口径对齐 |
| 每类 recall | 该类被正确识别的比例 | 看是否漏掉某一侧卧/俯卧 |
| 每类 precision | 预测为该类的样本中正确的比例 | 看误报 |
| macro-F1 | 四类 F1 的算术平均 | 类别不平衡时更公平 |
| 混淆矩阵 | 4×4 | 定位仰/俯、左/右混淆 |
| unknown 比例 | 输出 unknown 的时间占比 | 可用性 |
| 误切换次数/小时 | 稳定姿态之间的非真实切换 | 体验 |
| 过渡延迟 | 真实翻身到输出新姿态的时间 | 体验 |
| 丢包率 | `seq` 缺口/总帧数 | 数据质量 |

不要只报一个总准确率。四类里如果左侧卧很少，总准确率会被仰卧/俯卧拉高。设备端 5 s 迟滞用于实时显示，离线评估再按 30 s epoch 多数投票；**两种口径都报**。

## 7. 样本量与不确定性

单人原型阶段的目标不是统计显著性，而是**发现系统性问题**。建议：

- 静态四点：每类至少 9 分钟（3 轮 × 3 分钟）。
- 整夜：每类至少累计 30 分钟稳态数据，3 晚共 ≥ 90 分钟/类；侧卧通常更难凑，必要时白天补采。
- 报告准确率时给出 95% 置信区间（Wilson 区间）；不要用“95% 准确率”这种没有区间的说法。
- 如果要做受试者间推广，至少 5–10 人，且按人分组交叉验证；本阶段不做。

## 8. 文件与元数据

目录建议：

```
data/
  raw/          # 原始 CSV（只读，不手改）
  labels/       # 视频标注导出的时间段 CSV
  sessions.csv  # 每次采集的元数据
  processed/    # 特征/模型输出
```

`sessions.csv` 字段：

```
session_id,file,date,subject_code,night,sensor_position,strap_height_cm,
pajamas,blanket,pillow,mattress,start_time,end_time,notes
```

- `subject_code` 用 `S01` 这类代号，不写真实姓名。
- 不记录住址、电话、身份证号等个人信息。
- 原始 CSV 只读；所有清洗/裁剪生成新文件。

## 9. 失败分析与迭代顺序

出现低准确率时，按这个顺序排查：

1. **坐标/方向错**：`TOP` 是否朝头？左右是否反？先看静态四点。
2. **佩戴位移**：带子是否滑动、板子是否转到侧面？看整夜视频与重力分量漂移。
3. **被子/枕头**：被子把胸口压斜，`ay` 分量变大；看误判片段的重力向量。
4. **阈值/迟滞**：稳态也频繁跳变 → 提高切换阈值/保持时间；翻身反应太慢 → 降低保持时间。
5. **个体/姿势定义**：半侧卧、抱枕、蜷缩；决定是归入最近类还是 `unknown`。
6. **模型**：以上都排除后，再考虑随机森林/小型网络；不要用模型掩盖传感器/佩戴问题。

## 10. 安全与伦理

- 这是个人睡眠研究原型，**不是医疗器械**，不用于诊断或治疗。
- 带子不要勒得过紧；出现皮肤压迫、麻木、呼吸不适立即停止。
- 电池远离床铺充电；不要戴着设备充电；发现鼓包立即停用。
- 数据只保存在本地；分享结果时去掉可识别个人的信息。
