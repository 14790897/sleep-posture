**结论**：v0/v1 默认 **BMI270（C2836813）**，直接用 Espressif 托管组件 **`espressif/bmi270` v1.1.0**（I2C 低层驱动，自动加载 Bosch 配置固件，支持 ODR/量程配置和读取 g/dps）。该包不支持 SPI/FIFO/中断，但本项目 50 Hz 轮询用不上这些；FIFO/深睡留到 v2 再换 Bosch SensorAPI 或自己补。

**结论**：

**续航结论（重要）**：

- 连续 50 Hz BLE 推流 + 未做深度睡眠优化时，300–600 mAh 大约只能撑 **5–10 小时**（调研快照；必须实测）。整夜 8 h 用 500 mAh 属于“刚好够”，不要承诺 7 天。
- **7 天续航的前提**是：IMU FIFO + C3 深睡 + 每 10–30 s 醒来发一包姿态结果，而不是保持 1 Hz 实时连接或 50 Hz 原始流（500 mAh 估算约 12.8 天，仅估算）。
- v0 固件目前是 50 Hz 连续推流；整夜采集建议 `--rate 5` 或 10（仍 50 Hz 采样，降低 Notify 频率），并实测电流。
- v1 再实现 modem sleep / light sleep / 动态连接间隔；不要在没有实测前写“7 天”。

## 4. 不用 FPC 的取舍

| 方案 | 优点 | 缺点 | 决定 |
|---|---|---|---|
| FPC / rigid-flex | 贴合身体、薄 | 打样贵、装配/返修难、焊点易疲劳 | **不用** |
| 刚性 PCB + 硅胶线 | 便宜、好焊、好改 | 不能弯、需要软袋 | **采用** |
| 两块刚性板 + 排线 | 可分开放置 | 连接器/排线仍是薄弱点 | 暂不做 |

降低不适感的组合：

1. **24×38 mm**、0.8–1.0 mm 厚、R3 圆角、单面器件、最高 <3 mm；
2. 板子装薄布袋或 **Shore A20–A30 软硅胶药丸仓**，不直接贴皮肤；
3. 电池放侧袋/外侧，不与板子叠在胸骨正下方；
4. 4 芯 26–28 AWG 硅胶线（VCC/GND/SDA/SCL），套管选 **3 mm 内径**（2 mm 穿不下 4 根），留松弛 + 焊点打胶；
5. 弹性带 35–40 mm 宽，内侧防滑/防转，胸围适配范围写清楚（例如“适配 70–100 cm，织带弹性伸长 15–20 cm”，不要写成 70–130 cm 可调）。

## 5. 佩戴位置与文献预期

- **胸骨/胸骨旁单点**是四类可分性最好的位置；腹部次选（更舒适，但软组织/呼吸噪声大）；腰、背、腕、踝不建议作四类主方案。
- 文献要分开看指标和类别数：
  - 胸骨单点四类研究有 95.9%–99.2% 的报告，但样本多为 7–21 人、单夜、受控环境，不能直接外推到居家。
  - 俯卧是最难且最少见的类；有单研究报告俯卧敏感度约 **39%**（样本少、CI 宽），Hexoskin 右侧腰位的 65% 不能当成胸骨数据。
  - 真实居家合理预期：**总体 85%–95%**；俯卧单独看，不要用总体准确率掩盖。
- 中间姿态（±15° 窄主瓣之外）约占 40% 时间；±45° 四扇区分类会把这些强行归入最近类。建议输出连续角度 + 置信度，并保留 unknown/过渡。

## 6. 坐标约定

传感器坐标（元件面朝外、TOP 朝头）：

- `+X` = 受试者左侧
- `+Y` = 头侧
- `+Z` = 胸骨朝前/朝外

这是**右手系**：`X(左) × Y(头) = Z(前)`。不要写成“X=受试者右侧”，否则左右会反。

| 姿态 | 加速度计静止读数 |
|---|---|
| 仰卧 | `az ≈ +1 g` |
| 俯卧 | `az ≈ -1 g` |
| 左侧卧 | `ax ≈ -1 g` |
| 右侧卧 | `ax ≈ +1 g` |
