# 睡眠姿势检测原型计划

## 1. 目标

用一枚戴在躯干上的 IMU，区分 **仰卧 / 俯卧 / 左侧卧 / 右侧卧** 四种睡姿，并把原始数据与姿态结果通过 BLE 输出，供离线验证。

非目标（本阶段不做）：

- 不做呼吸/心率/睡眠分期等生理推断。
- 不做医疗诊断。
- 不做多人同时佩戴。
- 不做柔性 PCB/FPC。

## 2. 已定方案

| 项 | 决定 | 理由 |
|---|---|---|
| 传感器位置 | 胸骨（备选上腹部） | 躯干朝向最直接，四种姿态的重力分量可分 |
| 主控 | ESP32-C3 | 单核 RISC-V，BLE 够用，成本低，生态成熟 |
| 连接 | BLE GATT，自定义服务 | 手机/PC 都能接，功耗低于 Wi-Fi |
| 电路形态 | 刚性 PCB + 硅胶导线 + 弹性胸带 | **明确不用 FPC**；靠小板、软袋、电池分离解决舒适性 |
| 分类 | 重力矢量阈值 + 迟滞状态机 | 单人四类，物理量足够；先用可解释基线，再决定是否上 ML |
| 验证 | 视频/时钟做地面真值，按夜晚分组交叉验证 | 防止数据泄漏，结论可复现 |

## 4. 硬件路线

### v0：现成模块（优先）

目标：**一周内出第一段真实数据**，不把时间花在画板和等快递上。

- ESP32-C3 SuperMini 开发板 ×2（备一块）
- **BMI270 I2C 模块 ×2（默认，`espressif/bmi270` 包）**；LSM6DS3TR-C 模块可作备选
- 500 mAh 带保护板软包锂电（602535）+ TP4056 USB-C 充电模块
- 4 cm 弹性带、小布袋、26–28 AWG 硅胶线、JST-PH、热缩管

验收：能通过 BLE 以 50 Hz 连续推流 30 分钟，CRC 错误率 < 0.1%，静态四点分类正确。

### v0.5：SuperMini 载板（当前）

目标：不画 C3 模组/RF，直接把现成 SuperMini 当核心板，插到载板上，最快做出可穿戴实物。

- 载板 **30 × 50 mm，1.0 mm，2 层**，R3 圆角。
- 核心板：**ESP32-C3 SuperMini**（C3FH4 4MB），**直接贴片焊在载板两排 1×8 SMD 焊盘上（C9900004525），不用排针**；BMI270 用裸芯片 C2836813。
- 载板：**BMI270（C2836813）** + MCP73831（C424093）+ USB-C 充电口 + JST-PH + 电源开关 + 电池分压。
- 电池 500 mAh 602535（C5154891）放侧袋，JST-PH 线连接，不叠在天线附近。
- 供电：电池 → 开关 → SuperMini `5V` 脚，用 SuperMini 板载 LDO 出 3.3V；载板不再加 LDO。
- 详细原理图/网络表/JLCEDA 步骤见 `hardware/supermini-carrier-full-tp4056/`，BOM 见 `hardware/bom-supermini-carrier.csv`。
- 已生成嘉立创EDA专业版工程 `hardware/supermini-carrier-full-tp4056/`（原理图 + PCB）；PCB 使用**厂商库封装**（不是自定义封装），SuperMini 直贴 1×8 SMD 焊盘、BMI270 用裸芯片；自动布线 14/14，原生 DRC 间距/连接 0；只剩网表不同步 1。详见 `hardware/supermini-carrier-full-tp4056/`。

**重要**：编程时关掉载板电源开关，只插 SuperMini 的 USB-C；不要同时给 SuperMini USB 和 VSYS 供电。

验收：静态四点 + 整夜 3 晚数据可用；厚度/佩戴舒适度作为 v1 的改进依据。

### v1：裸模组薄板（以后可选）

目标：如果 v0.5 数据可用、但厚度/重量不能接受，再改裸模组。

- 24 × 38 mm，0.8–1.0 mm 厚，4 层，R3 圆角，单面器件。
- **ESP32-C3-MINI-1-H4X（C41349510）** + **BMI270（C2836813）** + MCP73831 + XC6220/ME6211 + USB-C + JST-PH。
- 电池 500 mAh 放侧袋；板子装薄布袋或软硅胶药丸仓；天线端伸出版边并留 ≥15 mm keep-out。
- 具体料号/价格见 `hardware/bom-pcb-v1.csv`，**下单前必须重新核对**。

> 当前优先做 v0.5；v1 只在 v0.5 验证后启动。

## 5. 固件设计

代码在 `firmware/`，ESP-IDF + NimBLE，已能编译出 `sleep_posture.bin`。

### 5.1 采样

- I2C 400 kHz；BMI270 50 Hz（`espressif/bmi270` 包配置）/ LSM6DS3TR-C 52 Hz，±2 g、±250 °/s。
- 采样任务 20 ms 周期（50 Hz），读 12 字节（陀螺 + 加速度）。
- v1 可改用 IMU FIFO + INT1 中断，降低 CPU 唤醒；v0 轮询足够。

### 5.2 校准

- **陀螺零偏**：设备静止 2 s，平均 200 个样本，写 NVS；主机发 `0x03` 触发。零偏只影响翻身检测，不影响静态重力分类。
- **安装方向**：v0 靠丝印 `TOP` + 固定佩戴；v1 预留“仰卧 10 s + 右侧卧 10 s”两姿态标定，解出传感器到身体的旋转矩阵（命令 `0x04/0x05` 已预留）。
- **加速度计**：出厂校准通常够用；若静态六面测试发现明显比例/零偏误差，再在 PC 端做六面最小二乘，不占固件 Flash。

### 5.3 姿态分类

对重力矢量 `(ax, ay, az)`（单位 g）：

```
|az| 最大且 az > +0.60  → 仰卧
|az| 最大且 az < -0.60  → 俯卧
|ax| 最大且 ax > +0.60  → 右侧卧
|ax| 最大且 ax < -0.60  → 左侧卧
其他                    → unknown（坐起/半躺/过渡）
```

> 坐标前提：元件面朝外、`TOP` 朝头；此时 `+X` 指向受试者左侧，所以 `ax > 0` 是右侧卧。

迟滞状态机（`firmware/main/posture.c`）：

- 从 unknown 进入某姿态：候选保持 3 s。
- 已稳定姿态切换到另一姿态：候选保持 5 s。
- 候选 unknown 持续 8 s：回到 unknown。
- 陀螺模长 > 60 °/s 或加速度模长偏离 1 g > 0.25 g：判定 moving；停止运动 2 s 后重新分类。
- 置信度按“最大分量 − 次大分量”的裕量给 0–99。

这套规则故意保守：宁可短时间输出 unknown，也不要在翻身过程中乱跳。真实睡眠姿态通常持续几分钟，5 s 切换延迟可以接受。文献常用 **30–60 s epoch** 做睡眠姿势统计；设备端保留 5 s 迟滞用于实时显示，离线评估时再按 30 s 多数投票平滑，两种口径都要报告。

### 5.4 BLE

- NimBLE，单连接，Service UUID `b7a10001-...`。
- Data 特征 50 Hz Notify 24 字节；Status 1 Hz Notify/Read 12 字节。
- 主机可发 `0x01 [rate]` 降采样（1–50 Hz），`0x02` 停止 Notify。
- v1 增加：断线后 LittleFS 离线记录、重连补传；v0 不做。

### 5.5 电源

- v0 连续 50 Hz 推流：研究快照约 **5–10 h**（300–600 mAh），必须实测；500 mAh 整夜 8 h 属于“刚好够”，不要承诺 7 天。
- 整夜采集建议 `--rate 5` 或 10（仍 50 Hz 采样，降低 Notify 频率），并实测整机电流。
- 7 天续航的前提是 IMU FIFO + C3 深睡 + 每 10–30 s 发一包姿态结果，而不是保持 1 Hz 实时连接或 50 Hz 原始流；500 mAh 估算约 12.8 天（仅估算）。
- 低功耗顺序：先关 Wi-Fi（本来就没开）→ 降低 Notify 频率 → 开 modem sleep → 再考虑 light sleep + BLE 共存。

## 6. 数据与验证

完整方案见 `docs/validation-protocol.md`。核心纪律：

1. 先台架六面，再佩戴四点，再整夜。
2. 每段姿态至少 3 分钟；分析时跳过每段前 10 s。
3. 视频 + 时钟做真值；不确定的片段标 unknown，不猜。
4. 按夜晚分组交叉验证，同一晚不能同时进训练和测试。
5. 先报混淆矩阵和每类 recall，再报总准确率。

## 8. 主要风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| 仰卧/俯卧混淆 | 被子把胸口压斜，az 不够大 | 看误判片段的重力向量；必要时把“被子下”作为单独数据层；调整阈值或加安装角标定 |
| 左/右混淆 | 带子旋转，ax 被 ay 分走 | 固定带子位置、丝印朝头；v1 两姿态标定；必要时用重力在身体平面的投影而不是单轴 |
| 侧卧不适 | 板子硌肋骨 | 小板、圆角、软袋、上移/移到上腹部对比 |
| 电池/导线 | 鼓包、断线 | 带保护板电池、应力释放、焊点打胶、每晚安检 |
| BLE 断连 | 整夜数据缺口 | v1 离线日志；v0 记录丢包率并在分析中剔除 |
| 单人过拟合 | 换人/换床就失效 | 本阶段只声明单人结果；多人需重新采集并按人分组验证 |
| 俯卧最难 | 俯卧召回低、总体准确率掩盖问题 | 单独报告俯卧 sensitivity/recall；文献单研究胸骨俯卧约 39%，不要承诺 90% |
| 天线/电池遮挡 | RSSI 差、整夜断连 | 天线伸出版边、电池远离天线；实测 on-body RSSI |
| MTU 不足 | 24B 帧被静默截断 | 固件等 MTU≥27 且订阅后再发；主机检查 `mtu_size` |
| 过度声称 | 把姿态当成睡眠质量 | 产品文案只说“姿势”，不做医疗/睡眠分期结论 |
